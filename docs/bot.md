# Описание Telegram-бота «Персональный повар»

## 1. Основное назначение
Telegram-бот выступает основным пользовательским интерфейсом (frontend) системы и выполняет функции:
- Первичный онбординг пользователя (сбор аллергий, вкусовых предпочтений и стартового списка продуктов);
- Навигация по разделам через постоянное меню (Reply Keyboard) и интерактивные инлайн-кнопки;
- Проксирование запросов пользователя к AI-агенту (LangGraph / Google Gemini) с сохранением контекста;
- Отображение сгенерированных вариантов блюд, пошаговых рецептов и интерактивное управление списанием продуктов.

---

## 2. Команды бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Приветствие пользователя, запуск пошагового FSM-онбординга (для новых пользователей) или вызов главного меню |
| `/help` | Справка по функциям бота, подсказки по голосовому/текстовому общению с шефом |
| `/reset` | Очистка истории текущего диалога с AI-агентом (при этом сохраненный профиль и продукты в холодильнике остаются в БД) |

---

## 3. Главное меню (Reply Keyboard)

| Кнопка | Поведение и сценарий |
| :--- | :--- |
| **🍽 Подобрать рецепт** | Открывает инлайн-кнопки выбора приема пищи: `[🥞 Завтрак] [🍲 Обед] [🍝 Ужин] [🥪 Перекус] [🎲 На усмотрение шефа]`. После выбора агент генерирует 2-3 варианта блюд под текущий холодильник |
| **🧊 Мой холодильник** | Выводит текущий список продуктов в холодильнике с инлайн-кнопками: `[➕ Добавить продукты]`, `[🗑 Очистить всё]`, `[🍽 Подобрать блюдо]` |
| **⚙️ Предпочтения** | Отображает карточку кулинарного профиля (аллергии, нелюбимые продукты, диета/предпочтения) и кнопки быстрого редактирования |
| **ℹ️ Помощь** | Выводит справочную информацию о возможностях бота и проекта |

---

## 4. Сценарии поведения бота

### 4.1. Пошаговый FSM-онбординг при `/start`
Онбординг реализован через механизм FSM (Finite State Machine) в aiogram для гарантированного и быстрого сбора данных без лишних вызовов LLM:
1. **Приветствие**: бот приветствует пользователя по имени и кратко рассказывает о возможностях персонального повара.
2. **Шаг 1: Аллергии и непереносимости**:
   - Бот спрашивает: *«Есть ли у вас аллергии или продукты, которые вы строго не употребляете?»*
   - Кнопка: `[🚫 Нет аллергий / Пропустить]`.
   - Пользователь вводит текст (напр.: *«арахис, креветки»*) или нажимает кнопку.
3. **Шаг 2: Вкусовые предпочтения и диеты**:
   - Бот спрашивает: *«Какую кухню предпочитаете или каких принципов питания придерживаетесь (вегетарианство, кето, ПП и др.)?»*
   - Кнопка: `[👌 Ем всё / Пропустить]`.
4. **Шаг 3: Стартовый список продуктов**:
   - Бот спрашивает: *«Какие продукты сейчас есть у вас дома? Напишите списком через запятую или построчно»*
   - Кнопка: `[⏩ Заполню позже]`.
5. **Завершение онбординга**: данные сохраняются в PostgreSQL, пользователю отображается главное меню. С этого момента все произвольные текстовые сообщения направляются AI-агенту.

### 4.2. Управление холодильником (гибридный подход)
- **Через меню бота**: по нажатию «🧊 Мой холодильник» выводится список продуктов. Нажатие кнопки `[➕ Добавить продукты]` переводит бота в режим ожидания списка продуктов (пользователь отправляет их текстом через запятую или по строкам). Кнопка `[🗑 Очистить всё]` удаляет все записи после подтверждения.
- **Через чат с AI-агентом**: пользователь может в любой момент написать боту обычной речью (например: *«Я докупил куриное филе, пачку риса и 10 яиц»* или *«Сыр закончился»*). AI-агент распознает намерения и вызывает соответствующие инструменты (`add_to_fridge` / `remove_from_fridge`).

### 4.3. Подбор блюда, рецепт и списание продуктов
1. Пользователь нажимает кнопку «🍽 Подобрать рецепт» или пишет запрос агенту (*«Что приготовить на ужин?»*).
2. Бот предлагает инлайн-кнопки выбора приема пищи.
3. AI-агент анализирует содержимое холодильника и аллергии/диеты из БД и формирует 2-3 кратких варианта блюд с акцентом на имеющиеся продукты.
4. Варианты выводятся пользователю с инлайн-кнопками выбора (`[1️⃣ Омлет с сыром]`, `[2️⃣ Паста с томатами]`).
5. При выборе блюда агент генерирует подробный пошаговый рецепт (время приготовления, ингредиенты из холодильника, если не хватает — пометка что докупить, и пошаговые шаги готовки).
6. Под рецептом отображается кнопка **«✅ Приготовлено (списать продукты)»**.
7. При нажатии этой кнопки:
   - В таблице `meal_plans` статус приема пищи переводится в `cooked`.
   - Бот предлагает в один тап подтвердить удаление израсходованных продуктов из холодильника.

### 4.4. Диалог с AI-агентом и передача сообщений
- Все текстовые сообщения пользователя, не являющиеся командами бота или шагами активного FSM-состояния, направляются непосредственно AI-агенту (LangGraph).
- Для каждого пользователя создается и поддерживается свой диалоговый поток (`thread_id`).
- Команда `/reset` позволяет сбросить диалоговый поток в LangGraph без удаления профиля и инвентаря пользователя.
