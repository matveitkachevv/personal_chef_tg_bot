# Описание telegram бота

## Основная задача
Основными задачами telegram-бота являются:
- Базовый сбор информации о пользователе;
- Прокси между backend приложением/AI агентом и пользователем. 

## Сценарии поведения бота

### Опрос пользователя

#### Опрос характеристик пользователя

В характеристики входят:
- Имя;
- Рост;
- Вес;
- Активность.

#### Опрос вкусовых предпочтений пользователя

Бот спрашивает о вкусовых предпочтениях пользователя для последующего формирования данных о пользователе.

#### Опрос на наличие аллергий на продукты

Бот спрашивает о наличие аллергий на продукты у пользователя для последующего формирования данных о пользователе.

#### Опрос для синхронизации списка имеющихся продуктов

Бот с определенной периодичностью опрашивает пользователя о наличии продуктов для сихнронизации данных в БД.

### Передача сообщений пользователя AI агенту.

Все сообщения пользователя уходят напрямую AI агенту, за исключением сообщений связанных с опросом пользователя ботом.
