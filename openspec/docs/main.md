# Название
Персональный повар

# Краткое описание
Телеграм бот, который занимается подбором рецептов и составлением меню на определенный прием пищи.

# MVP
Телеграм бот, который собирает информацию о вкусовых пожеланиях пользователя, а также наличии продуктов в холодильнике.
После сформированного представлении о пользователе, бот по запросу подбирает рецепты и составляет меню на определенный прием пищи.
Бот учитывает вкусовые предпочтения пользователя, наличие продуктов в холодильнике и предлагает рецепты, которые соответствуют этим критериям.

# Предлагаемый функционал для расширения

## Подбор рецептов по наличию белка в продуктах
Бот может анализировать продукты, которые есть у пользователя, и подбирать рецепты с учетом содержания белка в этих продуктах.
Это позволит пользователю готовить блюда, которые соответствуют его норме потребления белка, что особенно важно для людей, следящих за своим питанием или занимающихся спортом.
